# vaelix-website

Static placeholder site for [Vaelix Health](https://vaelix.health).

Hosted on GitHub Pages. Custom domain: `vaelix.health`.

## Files

- `index.html` — main landing page
- `privacy.html` — GDPR-minimum privacy policy
- `style.css` — minimal mobile-first stylesheet (light + dark mode)
- `CNAME` — GitHub Pages custom domain
- `robots.txt` + `sitemap.xml` — SEO basics

## Local preview

Open `index.html` directly in a browser, or:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

GitHub Pages serves the `main` branch root automatically. Any push to `main` triggers a new deploy in ~1 minute.
